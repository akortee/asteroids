## Описание проекта

«Астероиды» — двумерная аркадная игра на Python и Pygame с
тороидальным игровым полем, динамическим фоном, физикой движения корабля,
ракетами и анимацией взрывов.

## Функциональные возможности

- При запуске отображаются начальные жизни (3), начальный счёт (0),
  неподвижный фон, полупрозрачный динамический фон астероидов,
  движущийся влево с постоянной скоростью.
- Игра начинается при щелчке мышью на прямоугольнике заставки; клики
  вне заставки игнорируются. В центре появляется корабль, и в случайных
  местах поля с заданной частотой начинают генерироваться астероиды.
- Корабль вращается вокруг своего центра, ускоряется по направлению
  ориентации с переключением изображения на вариант с включёнными
  двигателями и стреляет ракетами из носа с постоянной скоростью.
- При выключенных двигателях корабль испытывает сопротивление среды
  и постепенно замедляется до полной остановки.
- Игровое поле имеет тороидальную геометрию: при пересечении границы
  любой объект появляется с противоположной стороны, сохраняя
  направление и величину линейной и угловой скорости.
- Астероиды имеют случайные линейную и угловую скорость при появлении
  и свободно проходят друг сквозь друга без столкновений.
- Ракеты имеют ограниченное время жизни, выбранное исходя из отношения
  размеров экрана к скорости полёта так, чтобы ракета не могла
  пролететь всё поле даже по малому измерению.
- При попадании ракеты в астероид оба исчезают, на месте астероида
  показывается анимация взрыва и начисляется одно очко.
- При столкновении корабля с астероидом астероид исчезает, на его
  месте появляется анимация взрыва, количество жизней уменьшается на 1,
  а корабль возрождается неподвижным в центре поля. При 0 жизней
  снова показывается заставка (корабль, астероиды и ракеты не рисуются),
  а счёт и жизни остаются на экране.

## Требования к системе

- Python 3
- Windows, macOS или Linux с графическим окружением
- Pygame (`pygame>=2.5.0`)

## Установка и запуск

Клонируйте репозиторий.

```bash
git clone https://github.com/akortee/asteroids.git
cd asteroids
```

Создайте и активируйте виртуальное окружение.

**Windows (PowerShell)**

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS и Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости и запустите игру.

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── assets/
├── src/
│   ├── __init__.py
│   ├── config.py
│   ├── models.py
│   ├── view.py
│   └── app.py
└── venv/
```

- `main.py` — точка входа в приложение.
- `src/config.py` — глобальные параметры игры и пути к ресурсам.
- `src/models.py` — модели объектов, физика и логика столкновений.
- `src/view.py` — загрузка изображений и отрисовка кадров.
- `src/app.py` — окно, обработка событий и главный цикл.
- `assets/` — спрайты и фоновые изображения.

Выделение классов в отдельные модули и разделение логики и отрисовки
повышают читаемость кода и позволяют удобно настраивать параметры игры
в одном месте.

## Управление

| Действие | Клавиша |
| --- | --- |
| Старт игры | Щелчок мыши по заставке |
| Вращение влево / вправо | `←` и `→` |
| Ускорение (двигатель) | `↑` |
| Выстрел ракетой | `Space` |
